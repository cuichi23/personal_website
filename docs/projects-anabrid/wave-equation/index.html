The wave equation on strings

Part of the work on the REDAC Technology Platform. This page is being written.

A string is the simplest system that carries a wave, which makes it the sharpest test of whether the machine keeps what it was given. Energy that should be conserved is a quantity you can check against, rather than a quantity you have to trust.

This page is work in progress. The description above is what the project is about; the measurements are not written up yet.
